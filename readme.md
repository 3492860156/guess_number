# 猜数字小游戏

## 项目简介
一个用 Python 编写的命令行猜数字小游戏，是我的一个 Python 练习项目。

## 游戏规则
1. 程序随机生成一个 1~100 的整数。
2. 玩家输入数字进行猜测。
3. 程序根据猜测提示“大了”或“小了”。
4. 猜中后游戏结束，并显示一共猜了几次。

## 运行环境
- Python 3.14.7
- Windows 命令提示符（cmd）

## 运行方法
1. 按 win + r，输入 cmd 打开命令提示符。
2. 进入项目目录：
   F:
   cd play_do\first
3. 运行程序：
   py guess.py

## 项目结构
- guess.py：游戏主程序
